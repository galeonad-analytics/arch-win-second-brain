# Second Brain

Персональный AI-ассистент архитектора — работает локально, данные не покидают машину.

**Платформы:** macOS (Apple Silicon) · Windows 11

> Первый запуск? → [INSTALLATION.md](INSTALLATION.md)

---

## Запуск

```bash
brain
```

Открой в браузере: **http://localhost:3030**

---

## Как работать с новым проектом

### 1. Получил задачу в Jira

Запомни номер тикета — например `ARCH-123`. Это твой ключ для всей работы с проектом.

---

### 2. Загрузи материалы

Открой **⊕ Загрузить проект** в UI.

Введи Jira тикет и путь к папке с документами проекта. Нажми **Загрузить и конвертировать** — система сама разберётся с форматами: PDF, Word, Excel, PowerPoint, изображения, диаграммы.

Когда конвертация завершится — нажми **Обработать через Ollama**. Локальная модель прочитает документы и разложит знания по нужным категориям.

---

### 3. Проверь что загрузилось

Открой **⚠ Пропущенные файлы** и выбери свой проект.

Если какие-то файлы не прочитались (например, сканы PDF) — система покажет их с пометкой. Нажми **⇪ Заменить** рядом с файлом и загрузи читабельную версию. Потом отметь галочкой и нажми **Переобработать**.

---

### 4. Спроси модель

Открой **◎ Спросить модель**, выбери проект.

Задавай вопросы на русском — модель ответит на основе загруженных документов:

- *Какие риски интеграции выявлены?*
- *Кто стейкхолдеры и каковы их интересы?*
- *Какие архитектурные решения уже приняты?*
- *Что осталось без ответа?*

Для глубокого анализа используй кнопку **✦ Claude API** — она отправит запрос в облако с тем же контекстом, но через более мощную модель.

---

### 5. Генерируй черновики артефактов

Открой **◈ Генерация артефакта**.

Выбери проект и тип документа (HLD, HLIS, AN, SPFA, BRD) — или загрузи свой шаблон. Выбери нужный раздел из шаблона и нажми **Ollama** или **✦ Claude API**.

Модель заполнит раздел на основе того что уже знает о проекте. Скопируй результат в свой документ в Confluence.

---

### 6. Прокачай модель скиллами

Открой **◆ Скиллы**.

Чем больше скиллов — тем точнее ответы модели. Два способа добавить скилл:

**Из базы знаний проекта** — выбери проект в дропдауне и нажми **◎ Создать из знаний проекта**. Модель извлечёт предметную экспертизу домена: что за системы, как работают, термины, бизнес-правила и точки интеграции.

**Из PDF книги** — укажи путь к PDF и нажми **▶ Создать скилл**. Подойдёт для методологий, фреймворков, вендорской документации.

Скиллы хранятся в `skills/` и подключаются к CLAUDE.md автоматически. Встроенный скилл `knowledge-processor` (сам CLAUDE.md) всегда виден в списке как read-only.

---

### 7. Появились новые материалы

Просто повтори шаги 2–3 для новой папки или файлов. Уже обработанные документы система пропустит автоматически.

---

### 8. Сохрани базу знаний

```bash
git add knowledge/ templates/ scripts/ skills/ CLAUDE.md
git commit -m "ARCH-123: обновление базы знаний"
git push
```

Сырые материалы (`raw/`) и API ключи (`.env`) в git не попадают — только структурированные знания.

## Что система знает о проекте

После обработки документов база знаний содержит:

- **Бизнес-контекст** — проблема, цели, границы, стейкхолдеры
- **Требования** — функциональные, NFR, безопасность
- **Архитектура** — AS-IS, TO-BE, интеграции, сценарии
- **Решения** — ADR с обоснованием и отклонёнными альтернативами
- **Риски** — с оценкой влияния и мерами митигации
- **Открытые вопросы** — что ещё не решено
- **Стейкхолдеры** — роли, интересы, RACI

Каждое утверждение трассируется до источника. Если источника нет — помечается `#hypothesis`.

---

## Что никогда не уходит в облако

Реальные имена людей, названия компаний-клиентов, коммерческие условия, сырые рабочие документы — всё это остаётся только локально. В Claude API отправляется только обезличенный контент из `knowledge/`.

## Дополнительно

- Просмотр связей между проектами → открой vault в **Obsidian** (`open ~/projects/second-brain`)
- Управление проектами → кнопка **✕** рядом с проектом в левой панели удаляет его из базы
- Смена локальной модели (llama, gemma, qwen...) → **⚙ Настройки** → Ollama модель
- Смена Claude модели или API ключа → **⚙ Настройки** (ключ опционален — если не задан, Claude API недоступен, но локальная модель работает)
- Обновить только модели без ввода ключа → **⚙ Настройки** → оставь поле ключа пустым и нажми Сохранить
- Просмотр бюджета Claude API → **⚙ Настройки** → ссылка на Anthropic Console
- Ручная настройка лимита токенов → **⚙ Настройки** → поле **MAX_CHARS** (если пусто — вычисляется автоматически по объёму RAM и размеру модели)
- Догрузить новые материалы в существующий проект → **⊕ Загрузить проект** → тот же Jira тикет, новый путь
- Остановить обработку → кнопка **■ Стоп** во время выполнения Ingest или Process
- Пропустить текущий файл не прерывая обработку → кнопка **⊘ Пропустить файл** во время Process
- Сохранить ответ Claude API в базу знаний → кнопка **⊕ Сохранить в знания** под ответом (сохраняет в `claude-insights.md` с тегом `#claude-generated #hypothesis`)
- Просмотреть или удалить скилл → **◆ Скиллы** → кнопка 👁 / ✕ рядом с каждым скиллом
- Применить глобальный скилл к проекту → **② Скилл проекта** → выпадающий список «Применить существующий скилл» → загружает содержимое в редактор → **Сохранить**
- Сделать скилл проекта глобальным → **② Скилл проекта** → кнопка **↑ Сделать глобальным** (появляется когда скилл сохранён) → вводишь имя → скилл копируется в `skills/` и становится доступен для всех проектов
- Спросить по нескольким проектам → **◎ Спросить модель** → нажимай чипы проектов для выбора (можно несколько) → задавай вопрос — ответ строится по объединённой базе знаний
- Генерировать артефакт по нескольким проектам → **◈ Генерация артефакта** → выбирай чипы проектов → контекст всех выбранных проектов объединяется в один запрос к модели

## Отличия Windows-форка от оригинала

Этот репозиторий — Windows-адаптация оригинального [second-brain](https://github.com/galeonad-analytics/second-brain).

| Область | Что изменено |
|---------|-------------|
| **Windows 11** | Полная поддержка: PowerShell, Win32 API, пути с кириллицей в именах файлов |
| **UTF-8 / кодировка** | `PYTHONIOENCODING=utf-8`, `--data-binary @file` вместо `-d` в curl, Python читает NDJSON из файла — устраняет искажения символов в пайплайне |
| **Python** | Автодетект `python` vs `python3` — на Windows `python3` может быть стабом Microsoft Store |
| **Таймаут** | OS-level `timeout` вместо `curl --max-time` — стриминг на Windows не прерывался по `--max-time` |
| **Кириллица в модели** | Автопереключение на `qwen2.5:7b` если основная модель не поддерживает кириллицу |
| **Гарблед-фильтр** | PDF с битой кодировкой (< 25% читаемых символов) пропускается автоматически без отправки в LLM |
| **Уникальность ID** | При добавлении знаний из нового файла счётчик продолжается с максимального существующего ID — дубли C-001/S-001 исключены |
| **epub / fb2** | Поддержка форматов электронных книг через pandoc |
| **poppler на Windows** | Корректное определение пути к `pdftotext` при нестандартной установке |
| **Heartbeat** | Индикатор прогресса каждые 30с при долгих LLM-запросах — показывает что скрипт жив |
| **MAX_CHARS авто-расчёт** | Лимит контекста вычисляется по объёму RAM и размеру модели (7B/13B/27B/70B); отображается в настройках, можно переопределить вручную |
| **Windows PATH** | Сервер автоматически добавляет в PATH: Git Bash, pandoc (AppData), Tesseract, ImageMagick — инструменты работают без ручной правки системных переменных |
| **Stop / Skip** | Кнопки остановки процесса и пропуска текущего файла прямо из UI во время Ingest/Process |
| **Claude insights** | Ответы Claude API сохраняются в `claude-insights.md` кнопкой «Сохранить в знания» с тегами `#claude-generated #hypothesis` |
| **Скиллы UI** | Кнопка удаления скилла, умный анализ (пропуск гарблед-файлов, выборка 8 наибольших) |
| **Обмен скиллами** | Применить глобальный скилл к проекту (select → Применить) и сделать скилл проекта глобальным (↑ Сделать глобальным → копирует в `skills/`) |
| **Мульти-проект чат** | Чипы выбора проектов вместо одиночного select в «Спросить модель» и «Генерация артефакта» — контексты объединяются, модель отвечает по всем выбранным проектам сразу |
